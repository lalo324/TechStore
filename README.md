
# 🛒 TechStore

Tienda virtual desarrollada con Vue 3, Pinia y Vue Router.

## 🌐 Proyecto publicado

https://lalo324.github.io/TechStore/

## 📌 Descripción

TechStore es una aplicación web de comercio electrónico que permite visualizar productos, administrar el catálogo y gestionar un carrito de compras.

## ⚙️ Tecnologías utilizadas

- Vue 3
- JavaScript
- Pinia
- Vue Router
- Vite
- HTML5
- CSS3

## 🚀 Funcionalidades

- Página de bienvenida.
- Página principal.
- Catálogo de productos.
- Registro de nuevos productos.
- Edición y eliminación de productos.
- Visualización de detalles.
- Carrito de compras.
- Almacenamiento de productos mediante localStorage.

## 💻 Instalación

Clonar el repositorio:

    git clone https://github.com/lalo324/TechStore.git

Entrar a la carpeta:

    cd TechStore

Instalar dependencias:

    npm install

Ejecutar el proyecto:

    npm run dev
